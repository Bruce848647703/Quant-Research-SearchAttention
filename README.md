# Quant-Research-SearchAttention

基于**互联网搜索关注度(搜索指数)**的多因子选股策略研究: 在沪深300成分股池中选股, 月度换仓, 含分层测试、Rank IC 分析与完整历史回测。

## 策略逻辑

行为金融中的"投资者关注"假说: 散户倾向于搜索近期有热点/异动的股票, 搜索热度对短期超额收益有预测力(中国市场多篇研究以百度指数验证)。本策略以下列因子加权合成综合得分, 每月末买入得分最高的 N 只(默认30), 等权持有:

| 因子 | 类型 | 方向 | 说明 |
|---|---|---|---|
| `search_heat` | 关注度 | + | 搜索热度水平: log(SI) 相对自身60日均值的偏离 |
| `search_mom` | 关注度 | + | 搜索热度动量: 20日 log(SI) 变化 |
| `attn_price_div` | 关注度 | + | 关注-价格背离: 热度已升但价格未动 |
| `mom_12_1` | 价量 | + | 12-1月动量 |
| `rev_5` | 价量 | − | 短期反转(买近5日跌的) |
| `low_vol_20` | 价量 | − | 低波动溢价 |
| `volume_ratio` | 价量 | − | 量能相对收缩(量比高者降权) |
| `amihud` | 价量 | + | Amihud非流动性溢价 |
| `lhb_heat` | 真实关注代理 | − | 龙虎榜上榜事件衰减强度(过热反转, 真实数据) |
| `lhb_net_buy` | 真实关注代理 | + | 龙虎榜净买额衰减均值(真实数据) |
| `gdhs_change` | 真实关注代理 | − | 股东户数近一年累计变化(散户化=关注度上升, 真实数据) |

合成方式(每个换仓日截面上): MAD去极值 → z-score标准化 → 按方向对齐 → 权重加权。单只股票部分因子缺失时, 权重按其实际可用因子重新归一(不按中性分填充); 可用因子比例低于 `min_valid_ratio`(默认0.5)的股票不参与选股。权重、方向与 `min_valid_ratio` 均在 `config/config.yaml` 中可调。

可选 `factors.neutralize`(默认关): 每个因子在去极值前先做**行业/规模中性化**(逐日截面对申万一级行业哑变量 + 规模代理回归取残差, 需先运行 `scripts/fetch_industry.py`)。**诊断结论**: 本策略的alpha主要来自行业/风格暴露, 全中性化后年化由~11%降至~4%, 故默认关闭, 保留供纯个股alpha研究使用。

加权方式由 `factors.weighting` 控制:

- `fixed`: 按上表固定权重加权;
- `ic_adaptive`(默认): 每个换仓日按该因子过去 `ic_weight_window`(默认12)期已实现的样本外 Rank IC 作权重(截断在0, 弱/反向信号因子自动降权至零)。`ic_weight_mode` 可选 `ic`(IC均值)或 `ic_ir`(默认, IC均值/IC标准差, 对波动大的因子降权更稳健)。权重仅用信号日收盘前已完全实现的历史IC, 无未来函数; 历史不足时退化为等权。

## 搜索指数与关注度数据

真实搜索指数(百度指数/微信指数等)无公开历史API, 本项目采用三层设计:

1. **真实搜索指数接入**: 将导出的指数CSV放入 `data/search_index/{股票代码}.csv`, 列名 `[date, index]`(列名可在config中改)。有文件的股票自动使用真实数据。
2. **真实关注度代理(推荐运行)**: `python scripts/fetch_attention.py` 抓取两类可回溯的真实关注数据(无需登录):
   - **龙虎榜**(东财, 2020起日频): 上榜=强关注事件, 榜单晚间披露、次日起可用;
   - **股东户数**(东财, 季频披露): 户数增加=筹码向散户分散, 以公告日为可知时点、次日起可用。
   缓存于 `data/cache/attention/`, 无缓存时回测自动跳过对应因子。
3. **合成搜索指数(兜底)**: 无真实数据的股票按无未来函数的行为模型生成合成指数 —— 热度对 t-1 及更早的涨跌、放量、偶发热点事件作 AR(1) 响应(即"行情驱动搜索", 与散户行为一致)。合成数据**仅用于跑通框架**, 不代表真实市场数据。

## 快速开始

```bash
pip install -r requirements.txt
python scripts/fetch_data.py      # 抓取沪深300成分股+日线(腾讯源, 后复权)+基准指数, 缓存在 data/cache
python scripts/fetch_attention.py # 抓取真实关注度代理: 龙虎榜+股东户数(可选, 无登录)
python scripts/fetch_industry.py  # 抓取申万行业分类映射(行业中性化用, 可选)
python scripts/run_backtest.py    # 因子 -> 回测 -> results/report.md + results/plots
python tests/test_factors.py      # 无未来函数、因子缺失处理、IC统计、引擎成本等单元测试
```

输出位于 `results/`: `report.md`(报告)、`nav.csv`、`quantile_returns.csv`、`factor_ic.csv`、`holdings.csv`(每期持仓)、`plots/*.png`。

## 回测设定

- 股票池: 沪深300成分股。已用成分股 `include_date` 做**准点位还原**(信号日未纳入的股票不参与选股); 但快照无剔除日期, 已剔除股票仍保留, 属部分还原
- 行情: 腾讯K线, **后复权(hfq)**, 拉取时校验脏数据(负价/单日波动>26%)并自动重试
- 信号: T日收盘后计算; 成交: T+1日开盘价; 月度(月末交易日)换仓
- 交易成本: 单边 15bp(佣金+印花税+滑点), `cost_bps_one_way` 可调
- **换手缓冲带**(`buffer_ratio`, 默认0.3): 原持仓排名仍在 top_n*(1+buffer) 内的不卖出, 仅用卖出回笼资金买入新入选股, 降低换手与成本
- **涨跌停不可成交**(`limit_check`, 默认开): 开盘即涨停(主板≥+9.8%/创科≥+19.8%)视为买不进, 开盘即跌停视为卖不出(继续持有到下期)
- 剔除数据不足120日的股票; 停牌按最后价格估值(复牌即以开盘价交易)
- 诊断项: 5分层净值、各因子(执行口径 open→open 前瞻收益)Rank IC 及 t 值、换仓股票名换手率、**前后半样本分段绩效**(过拟合检查)

## 目录结构

```
config/config.yaml        # 数据区间/因子权重/回测参数
scripts/fetch_data.py     # 行情数据抓取(缓存)
scripts/fetch_attention.py# 真实关注度代理抓取(龙虎榜+股东户数)
scripts/fetch_industry.py # 申万行业分类映射抓取(行业中性化用)
scripts/run_backtest.py   # 端到端回测
src/data/                 # 成分股、行情、搜索指数(真实+合成)、关注度代理、行业映射
src/factors/              # 关注度因子、价量因子、关注度代理因子、合成流水线
src/backtest/             # 换仓引擎、指标、报告
data/cache/               # 行情与关注度数据缓存(parquet, 已gitignore)
results/                  # 报告与图表
tests/                    # 无未来函数与引擎口径测试
```

## 主要局限

- 准点位还原仅用纳入日期, 无剔除日期, 幸存者偏差只能部分消除; 行业分类为当前静态快照
- 涨跌停不可成交为一字板近似(仅看开盘价是否触板), 未建模盘中封板与部分成交
- 合成搜索指数不携带真实投资者情绪信息; 龙虎榜对大盘股偏稀疏(沪深300平均每年约2次上榜), 东财人气榜接口受网络限制未能接入
- 股东户数接口对部分股票无数据(约4%), 对应股票该因子按缺失处理
- 后复权价格与当前真实成交价相差一个累计除权因子, 收益率口径不受影响
